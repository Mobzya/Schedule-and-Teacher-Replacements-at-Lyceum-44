# Lyceum 44 Schedule Bot v3

Telegram-бот расписания Лицея №44, переписанный для учебного года 2026–2027 вокруг **управляемых источников**, безопасной публикации и понятного интерфейса для ученика.

## Что изменилось принципиально

### 1. Больше нет двусмысленного «уроков нет»

Бот различает:

- **WAITING** — расписание нового года ещё не опубликовано;
- **READY + неучебный день** — праздник/выходной/каникулы;
- **READY + нет данных класса** — источник на эту дату/класс ещё не загружен;
- **READY + расписание** — показываются уроки.

Пока система в WAITING, ученики видят:

> 🟡 Расписание 2026/27 ещё не опубликовано. Бот уже работает; после загрузки и проверки расписания оно появится автоматически.

При этом `/start` уже регистрирует пользователя, поэтому администратор может заранее сделать массовое уведомление.

### 2. Источники больше не зашиты в код

Администратор управляет ими прямо из Telegram:

`🛠 Админ → 📡 Источники`

Поддерживаются:

- `weekly_schedule` — постоянное недельное расписание;
- `date_schedule` — временное расписание **на одну дату**;
- `replacements` — замены.

Можно добавить обычную Google Sheets ссылку вида:

```text
https://docs.google.com/spreadsheets/d/.../edit?usp=drivesdk
```

Если в ссылке нет `gid`, бот скачивает всю книгу и объединяет все видимые вкладки
подходящего формата и учебного года. Ссылка с `gid=` импортирует только указанную вкладку.

### 3. Безопасный процесс публикации

Добавленная ссылка проходит этапы:

1. скачивание;
2. распознавание формата;
3. проверка учебного года;
4. подсчёт найденных уроков/замен;
5. предпросмотр;
6. только после подтверждения — сохранение snapshot;
7. **отдельная кнопка `✅ Опубликовать + уведомить`** открывает данные ученикам.

Плохой CSV, старый учебный год или недоступный Google Sheets не уничтожают последний рабочий snapshot.

### 4. Старые ссылки 2025/26 оставлены как наблюдаемые legacy sources

В `.env.example` сохранены старые Spreadsheet/GID из прежнего проекта. Они опрашиваются, но лист с явно указанным `2025-2026` получает статус `stale` и **не заменяет данные 2026/27**.

Если лицей просто обновит содержимое тех же вкладок на `2026-2027`, источник автоматически начнёт проходить проверку. Если создадут новый Google Spreadsheet или новую вкладку с новым `gid`, добавьте новую ссылку через Telegram.

Старая таблица замен не подключается: в ней нет учебного года, поэтому короткие даты нельзя
безопасно отличить от дат 2026/27. В новой таблице добавьте явную строку `2026-2027 учебный год`.

### 5. Временное расписание на один день

Для текущей ситуации начала сентября используйте:

`Админ → Источники → ➕ Расписание на дату`

1. введите дату;
2. отправьте ссылку;
3. проверьте число найденных записей;
4. сохраните;
5. опубликуйте.

Такой источник действует только на выбранную дату и имеет приоритет над недельным расписанием. Он не портит постоянную сетку.

Парсер понимает два формата:

**Матричный** — классы по столбцам, рядом кабинет (как старые лицейские таблицы).

**Табличный**:

```text
Класс | Урок | Предмет | Кабинет
10а   | 1    | Алгебра | 316
10а   | 2    | Физика  | 301
```

Для недельного табличного формата добавьте `День` / `День недели`.

## Ученический интерфейс

Главный экран — одно редактируемое сообщение:

```text
🏫 Лицей №44 · 10а
📆 Вторник, 01.09 · 10:34

🟢 Сейчас
3. Физика · каб. 301 · 10:15

⏭ Дальше
4. Алгебра · каб. 316 · 11:15

[📅 Сегодня] [📆 Неделя]
[⚡ Изменения] [⚙️ Настройки]
[🎓 Мой класс] [🔄 Обновить]
```

Доступны:

- сегодня;
- неделя назад/вперёд;
- только изменения своего класса;
- выбор класса и профиля;
- напоминания за 5/10/15/20/30/45 минут;
- уведомления о заменах;
- утренняя сводка.

При смене `ACADEMIC_YEAR` прошлогодний класс не считается актуальным: пользователь выбирает его заново.

## Админ-панель

`/admin` или кнопка `🛠 Админ`.

Основные действия:

- `📡 Источники` — добавить/проверить/включить/выключить/удалить;
- `🔄 Синхронизация` — проверить все источники сейчас;
- `🚦 Публикация` — WAITING ↔ READY;
- `📣 Напомнить всем: расписание ожидается`;
- `✅ Опубликовать + уведомить`;
- `✏️ Сообщение ожидания`;
- произвольная рассылка с предпросмотром.

Календарные исключения:

```text
/dayoff 2026-11-04 праздник или каникулы
/schoolday 2026-09-12 0 учимся по понедельнику
/dayclear 2026-09-12
```

Федеральные праздники РФ учитываются автоматически; явное решение администратора имеет приоритет.

## Время звонков

В `.env` есть:

```dotenv
BELL_SCHEDULES_JSON={"main":[["08:15","09:00"],...]}
CLASS_BELL_SCHEDULES_JSON={}
```

Можно завести несколько наборов для корпусов/смен и привязать класс:

```dotenv
CLASS_BELL_SCHEDULES_JSON={"7а":"campus2_first","7б":"campus2_second"}
```

Если для класса указан неизвестный набор звонков, бот **не угадывает время** и не отправляет потенциально неправильные напоминания; предметы и кабинеты остаются видимыми.

# Быстрый запуск

## 0. Обязательно перевыпустите Telegram token

Старый token был опубликован в публичном репозитории. В `@BotFather` отзовите его и создайте новый.

Перевыпуск сохраняет самого бота, его ID и аудиторию, но немедленно лишает старый token
доступа. Затем верните имя, описание и аватар через `@BotFather` и задайте новый token только
в `.env` или в secrets хостинга. Никогда не вставляйте его в код, issue, commit или лог.

## 1. Окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Python: 3.11–3.14; рекомендуется 3.13.

## 2. Настройки

```bash
cp .env.example .env
```

Минимально заполните:

```dotenv
BOT_TOKEN=НОВЫЙ_ТОКЕН
ADMIN_IDS=ВАШ_TELEGRAM_ID
ACADEMIC_YEAR=2026-2027
DATABASE_PATH=./data/schedule_v3.db
DATABASE_URL=
```

Telegram ID можно узнать через `/id`.

## 3. Проверка

```bash
pytest -q
python -m scripts.self_check
```

## 4. Запуск

```bash
python -m app.main
```

Откройте:

```text
http://localhost:10000/health
```

## 5. Что сделать прямо сейчас, пока постоянного расписания нет

1. Запустите bot в WAITING (это состояние по умолчанию).
2. Если есть старая `schedule.db`, перенесите пользователей:

```bash
python -m scripts.migrate_legacy_db /path/to/old/schedule.db
```

Настройки уведомлений переносятся, прошлогодний класс намеренно сбрасывается.

3. Откройте `/admin → 🚦 Публикация`.
4. Нажмите `📣 Напомнить всем: расписание ожидается`.
5. Когда появляется временный лист — `📡 Источники → ➕ Расписание на дату`.
6. Введите дату и вашу Google Sheets ссылку.
7. Убедитесь, что предпросмотр нашёл ожидаемое количество уроков.
8. Сохраните источник.
9. Нажмите `✅ Опубликовать + уведомить`.
10. Когда появится постоянная сетка — добавьте её как `Основное расписание` и синхронизируйте.

# Render Free

`render.yaml` настроен на бесплатный Web Service. В production задайте `DATABASE_URL` внешней PostgreSQL-базы:
локальная SQLite на Render Free не переживает restart или redeploy. Полная инструкция находится в
[`docs/render-free-deploy.md`](docs/render-free-deploy.md).

# Тесты и CI

GitHub Actions запускает:

```text
pip check
pytest
python -m scripts.self_check
```

на Python 3.11 / 3.13 / 3.14.

# Безопасность

В архив не входят:

- `.env`;
- Telegram token;
- production SQLite DB;
- `__pycache__`;
- виртуальное окружение.

Секреты также исключены из Docker build context через `.dockerignore`.
